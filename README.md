# 回路図

テキスト記法で書いた回路を、回路図として描くブラウザアプリです。
`index.html` 1 ファイルだけで動き、インストールやアカウントは要りません。外部のサービスを読み込まず、書いた内容をどこにも送信しません。

電気回路・電子回路・Arduino とセンサーをつなぐ回路を、学生が正しい記号で描けるようになるためのツールです。記号の描き方は、日本の高校の教科書などで使われる「日本式」、JIS C 0617・IEC 60617 の図記号どおりの「JIS/IEC」、米国の現場でよく見る「米国式」から選べます(下の「記号の流儀」)。

- テキストを書くと回路図が自動で描かれる(線は手で引かない)
- 抵抗や LED は `U1.D13 -- R1 -- D1 -- GND` のように連鎖で書け、書いた向きがそのまま LED などの向きになる
- Arduino の機種やセンサーは、ピンの並びを `part` で定義して使う
- 極性の誤り(LED の逆向き、抵抗のない LED など)や書き間違いを警告する
- 記号を日本式・JIS/IEC・米国式で切り替えられる
- テキスト(.txt)で上書き保存・別名で保存(Ctrl+S)。SVG・PNG・JSON に書き出し、印刷で PDF にできる
- 生成 AI にテキストを書かせて、そのまま貼れる

## 使い方

公開版は https://circuit.sapp.jp で使えます。
ダウンロードした `index.html` をブラウザで直接開いても使えます。

1. 公開版か `index.html` を、ブラウザ(Edge・Chrome など)で開きます。
2. 左の欄に回路を書きます。右に回路図が出ます。書き方は画面上部の「書き方」ボタンで見られます。
3. 右の記号・線・電源記号をクリックすると、下に編集パネルが出ます。

初めて開いたときは空です。2 回目からは、前に書いていた内容が入った状態で開きます(下の「保存と読み込み」)。「例を読み込む」を押すと Arduino の例が入ります。高校の直流回路の例は「書き方」の中から読み込めます。

## 生成 AI で回路を書かせる

入力がテキストなので、生成 AI が書いたテキストをそのまま貼るだけで回路図になります。
ただし、このアプリの記法は独自のものなので、AI は最初から書き方を知りません。

ChatGPT・Claude などの生成 AI に書いてもらうときは、最初に指示文の中身を AI に渡してください。指示文は 2 種類あります。

| 指示文 | 使う場面 |
|---|---|
| `docs/prompt_for_ai.md` | 全部入り。高校の電気回路(電池・電球・電流計など)も含む |
| `docs/prompt_for_ai_hackathon.md` | Arduino とセンサー用。使う機種とセンサーの `part` 定義を書き足して渡す |

1. 指示文の中身を AI に貼る(またはファイルを添付する)
2. 続けて、作りたい回路の内容を伝える(例:「Arduino Uno の D9 にスイッチをつなぎ、押すと LED が点く回路」)
3. AI が書いたテキストを、左の欄に貼る
4. 右の回路図と、左下のメッセージ(エラーは行番号つきで、警告は内容つきで出ます)を確認し、直したい点を AI に伝える

## 書き方

画面上部の「書き方」ボタンでも一覧を見られます。1 行に 1 つの文を書き、`#` から行末まではコメントです。

| 書き方 | 意味 |
|---|---|
| `名前 = 種類 値` | 部品を置く(例 `R1 = R 220Ω`、`D1 = LED 赤`)。値は省略でき、書いたとおりに図に出る。値に `#`・`"`・`--` は使えない |
| `A -- B -- C` | 同じ接続にする。`--` の前後には空白が必要 |
| `部品.ピン` | 部品のピン(例 `U1.D13`、`D1.K`、`C1.+`)。最初の `.` で区切るので `U1.3.3V` も書ける |
| `GND`、`5V`・`3.3V`・`12V` など「数字 + V」 | 電源の記号として描く(`+5V` は `5V` と同じ電源) |
| 上のどれでもない名前(例 `out`、`a`) | 接続の名前。同じ名前どうしを線で結ぶ(名前は図に出ない)。使える文字は英数字と `_` `+` `-` |
| `part 種類名 "説明":` | 部品の種類を定義する(下の「部品の定義」) |
| `place A below B` | 配置のヒント。部品 A(を含む連鎖の行、または箱)を B の下に置く。`above`・`left`・`right` も使える。書かなければすべて自動 |

- ピンが 2 本の部品(`NOT` ゲートを除く)は、`U1.D13 -- R1 -- D1 -- GND` のように部品名だけを連鎖の途中に置けます。連鎖の入る側が、下の表のピンの 1 番目(極性のある部品ではアノード・+)になります。
- 部品名だけを書けるのは連鎖の途中だけで、1 つの部品につき 1 回です。連鎖の端や 2 回目からは `D1.K` のようにピンで書きます。逆向きに使うときもピンで書きます。
- トランジスタ・ボリューム・MOS FET・オペアンプ・論理ゲート(`NOT` も含む)は、いつも `Q1.B`・`VR1.2`・`U1.OUT` のようにピンで書きます。
- オペアンプの電源のピン `V+`・`V-` は省略でき、つないだときだけ描きます。`U1.V+ -- 12V`、`U1.V- -- -12V` のように電源につなぐと、電圧が図に出ます。
- 左のテキストに構文エラーがある間は、右の図が薄く表示され、記号をクリックしての編集はできません(直前の正しい図のままです)。

## 部品の定義

Arduino の機種やセンサーなど、組み込みにない部品は `part` で定義します。字下げした行に、ピンを出す辺とピン名を書きます。

```
part HC-SR04 "超音波距離センサー":
    top    VCC
    left   TRIG ECHO
    bottom GND
```

- 辺は `top` / `left` / `right` / `bottom`。左右の辺は上から、上下の辺は左から書いた順に並びます。
- `|` を 1 つ書くごとに 1 つ空きを入れます。`D13/SCK` のように `/` で別名を付けられ、どちらの名前でも同じピンを指します。
- `VCC@14` のように `@` の後に書いた番号は、IC の物理ピン番号として引き出し線の外側に出ます。
- 電源は上、GND は下、入力は左、出力は右に置くと図が読みやすくなります。
- ピンが 2 本だけの部品は、辺の指定によらず、抵抗などと同じく連鎖に入る小さな箱として描かれます(説明の文字は出ません)。
- 図には使っているピンだけが出ます。全部のピンを出すときは、画面上部の「使っていないピンも表示」を選びます。

## 警告

図は描いたうえで、左下に次の警告を出します。

- 部品の両端が電源・GND に直接つながっていて向きを判断できるときの極性の誤り(LED・ダイオード・ツェナーダイオードの順方向の直結、LED の逆向き、電解コンデンサの逆向き)
- 部品の端子がどこにもつながっていない
- 接続の名前が 1 回しか書かれていない(書き間違いの疑い)
- 部品の両端が同じ接続につながっている(短絡)
- 電源どうしが直接つながっている(例 `5V` と `GND`)
- `place` で同じ連鎖の中の部品どうしを指定した(その指定は使われない)

両端の電位がわからない場所の極性は判断しません。
線で結べない接続があったときは、その接続を名前のラベルでつなぎ、その旨を左下に出します。

## 編集パネル

右の記号をクリックすると、下に編集パネルが出ます。

| 操作 | 内容 |
|---|---|
| 「値」の欄を書き換えて Enter | 部品の値を変える。左のテキストの該当行が書き換わる(Ctrl+Z で戻せる) |
| テキストのこの行へ | 左のテキストで、その部品を置いた行を選ぶ |

線(導線)をクリックすると、その接続の線がすべて色付きになり、編集パネルにその接続を書いた行(つなぐ文)が「12 行目」のように並びます。押すと左のテキストのその行を選びます(行が 1 つだけのときは、クリックしただけでその行を選びます)。電源記号(`GND`・`5V` など)をクリックしたときは、その記号につながる端子を書いた行だけが並びます。

線を手で引くことはできません。接続はテキストで書き、線はそれに合わせて引かれます。

## 記号の流儀

画面上部の「記号」で、記号の描き方を選びます。テキストの書き方・配置・線の引き方は同じで、記号の形だけが変わります。選んだ記号の流儀は見た目の設定なので、テキスト(.txt)には入りません。このブラウザに残るほか、書き出した SVG・JSON には入ります。

### 日本式(既定)

JIS C 0617 を基本に、日本の高校の教科書などで使われる形です。抵抗は長方形、電池は長い線が +、電球は円に ×、電流計・電圧計は円に A・V です。JIS C 0617 のとおりではなく、わかりやすさを優先した箇所があります(電流計・電圧計の + 印、トランジスタの円、交流電源の円に ~)。

### JIS/IEC

JIS C 0617 と国際規格 IEC 60617 の図記号どおりの形です。JIS C 0617 の各図記号は IEC 60617 の図記号と対応しているので、使うすべての記号を両方の番号で示せます。日本式のうち JIS C 0617 のとおりに描いている部品は同じ形です。日本式と形が変わるのは次の部品です。

| 部品 | JIS/IEC の形 | 図記号 |
|---|---|---|
| 電流計・電圧計 | 円に A・V(+ 印なし) | JIS C 0617-8 08-02-01 ほか |
| ボリューム | しゅう動接点の矢印を、横から来て下に折れる L 字形にする | JIS C 0617-4 04-01-05 |
| トランジスタ | 円なし、エミッタの矢じりは開いた形 | JIS C 0617-5 05-05-01 ほか |
| MOS FET | 矢じりを開いた形にする | JIS C 0617-5 05-05-11〜16 |
| オペアンプ | 長方形に ▷∞ | IEC 60617 S01782(JIS C 0617-13 13-09-01) |
| 論理ゲート | 縦長の長方形の上端に &(AND)・≥1(OR)・=1(XOR)・1(NOT)、否定は出力の丸 | JIS C 0617-12 12-27-01・02・09・11、12-28-01・02 |

交流電源の「円に ~」は、JIS C 0617-2 の 02-02-20(交流電源)、IEC 60617 の S01903(AC power supply)です。

### 米国式

米国の現場でよく見る形で、IEEE 315(論理ゲートは IEEE 91)を基本にしています。日本式と形が変わるのは次の部品です。

| 部品 | 米国式の形 |
|---|---|
| 抵抗・可変抵抗・ボリューム | ギザギザ(可変抵抗は斜めの矢印、ボリュームはしゅう動接点の矢印を付ける) |
| 電解コンデンサ | 直線の板(+)と曲線の板 |
| ツェナーダイオード | 棒の両端を逆向きに曲げた形 |
| 押しボタンスイッチ | 2 つの端子の丸の上に棒と軸 |
| 電球 | 円の中にフィラメントの輪 |
| トランジスタ | 円なし |

### どの流儀でも同じ形

コンデンサ、コイル、ダイオード、発光ダイオード、電池、交流電源(円に ~)、スイッチ、モーター、接地は、どの流儀でも同じ形です。MOS FET は、どの流儀でも JIS C 0617 のサブストレートをソースに接続した形(円なし。P チャネルは上下を入れ替えてソースを上にする)で描きます(矢じりの形だけ JIS/IEC が開いた形)。ツェナーダイオードは、日本式・JIS/IEC が棒の下端だけをアノード側へ折る形(JIS C 0617-5 05-03-06)です。

電流計・電圧計の + 印は日本式・米国式だけに付けます(JIS/IEC では付けません)。オペアンプは日本式・米国式が三角形、論理ゲートは日本式・米国式が MIL 記号です。オペアンプの入力は、どの流儀でも + が上、- が下です。

## 用紙

画面上部の「用紙」で なし / A4 縦 / A4 横 を選びます。既定は「なし」(1 枚の図)。

- A4 を選ぶと、図を 1 ページに収まるように縮小して表示します(ページには分けません)。
- 画面のページ枠は、保存・印刷には出ません。

## 保存と読み込み

| 操作 | 内容 |
|---|---|
| 上書き保存(Ctrl+S、Mac は ⌘S) | 開いている・保存したテキスト(.txt)に書き戻す。まだファイルがないときは「別名で保存」と同じ |
| 別名で保存 | 保存先とファイル名を選んで、左の欄のテキストを .txt で保存する。正本はこのテキスト |
| 書き出し… → SVG | ベクター画像。テキストと設定を埋め込んであるので、このアプリで開いて編集を続けられる |
| 書き出し… → PNG | 画像(3 倍解像度) |
| 書き出し… → JSON | テキストと、記号・用紙・使っていないピンの表示の設定をまとめたもの |
| 書き出し… → 印刷 / PDF | ブラウザの印刷。送信先を「PDF に保存」にすると PDF になる。紙は、用紙「なし」なら図と同じ大きさ(余白なし)、「A4 縦 / A4 横」ならその向きの A4 |
| 開く / ドラッグ & ドロップ | `.txt` `.json`、このアプリで書き出した `.svg` |

- 上の帯に、開いている・保存したファイル名を出します。後ろの `*` は、保存していない変更があることを示します。保存していない変更があるときは、「新規」「開く」「例を読み込む」で確認が出ます。
- Chrome・Edge では、開いた .txt(ドラッグ & ドロップで開いたものも含む)にそのまま上書きします。ほかのブラウザでは、同じ名前でダウンロードします。
- JSON・SVG を開いたときは、そのファイルには上書きしません(書き出しの形式のため)。最初の上書き保存で、.txt の保存先を尋ねます。
- 記号・用紙・使っていないピンの表示は見た目の設定なので、テキストには入りません。設定はブラウザに残るほか、SVG・JSON に書き出すと一緒に入ります。

他のツールで描いた SVG や PNG は開けません(図の形からではなく、埋め込まれたテキストから描き直すためです)。

書いている内容(テキストと、記号・用紙などの設定)は、ブラウザの `localStorage` にも自動で保持されます。ページを閉じても、次に開くと続きから使えます。保持先はこのパソコンのこのブラウザの中だけで、外部には送信しません。ただし、次の点に注意してください。

- 保持先はブラウザごと、サイト(URL)ごとです。別のブラウザや別の場所の `index.html` で開くと、別の保持先になります。
- ブラウザの「サイトデータの削除」で消えます。残したい回路は、必ず「上書き保存」か「別名で保存」でファイルに保存してください。
- ファイル名と、保存していない変更があるかどうかも保持します。ただし上書きの先は保持しないので、開き直した後の最初の上書き保存では保存先を尋ねます。
- 保持できなかったとき(容量超過や、保存を許可しない設定など)は、左下に警告が出ます。
- 同じ回路図を 2 つのタブで開いて編集すると、後から書いた方が残ります。別のタブで編集されたときは、左下に警告が出ます。
- 「新規」を押すと、保持されている内容も空になります。

## 報告書に載せる

- TeX: 用紙を「なし」にして「書き出し… → 印刷 / PDF」を選び、印刷の画面で「PDF に保存」を選びます。紙が図と同じ大きさ(余白なし)になるので、`\includegraphics[width=\linewidth]{circuit.pdf}` のようにそのまま読み込めます。Chrome・Edge で使ってください。
- Word・スライド: SVG か PNG を貼ります。シンプルスライド(https://slide.sapp.jp)には SVG をそのまま貼れます。

## 動作環境

Edge・Chrome などの最近のブラウザで動きます。ネット接続が必要なのは公開版のページを開くときだけで、ダウンロードした `index.html` は接続しなくても動きます。
